## ✨ 它是什么

「日行」是一个**不联网、不注册、没有广告**的安卓学习计划 App。

打开应用，你会看到一朵由四片花瓣组成的丁香：

- 🌸 **每日箴言** —— 轻点换一句
- 🎯 **今日进度** —— 今天任务完成率
- 🕗 **今日课程** —— 课程的起止时间
- 📖 **单词本** —— 固定在首页，点进去就能背

花心显示你已经坚持的天数。下面才是本周打卡和任务列表——首页只留一句问候，把光晕和花瓣留给最重要的事。

> 数据只存在你的手机里；需要换机时，用「备份与恢复」导出，或两台设备在同一 Wi-Fi 下「设备互连」对齐进度。

## 🚀 快速上手

### 1. 把课表导进来

课表页右上角「导入」，支持三种方式：

- **粘贴文本**（一行一节课）：
  ```
  周一 08:00-09:40 高等数学 教学楼A302 张老师
  周二 10:00-11:40 大学英语 外语楼B205 李老师
  周三 14:00-15:40 专业课 综合楼C101
  ```
- **选择 CSV / TXT 文件**（同上格式）；
- **选择 JSON 文件**（数组，字段 `weekday/start/end/name/place/teacher`）。

导入前会显示解析结果与重复课程数量，可选择「追加」或「替换全部」。导入后**科目会自动按课程名生成**，任务和笔记里就能按科目归类了。

### 2. 每天怎么用

- 早上看一眼首页：今天几节课、要做哪几件事；
- 做任务时点圆圈勾选（可先点条目改标题/时间/优先级）；
- 学习时切到「专注」开一个番茄钟（可自定义时长，结束自动计入统计）；
- 通勤/碎片时间背单词，点卡片看释义，认识点「认识」、不认识点「不认识」；
- 「我的 → 学习统计」看这周学了多久。

### 3. 两台设备对齐进度（设备互连）

1. 两台设备连**同一个 Wi-Fi**；
2. 设备 A：`我的 → 设备互连 → 开启互连`，记下显示的 `IP:端口` 和 4 位连接码；
3. 设备 B：输入地址和连接码 → `连接并同步`；
4. 之后每次需要对齐时重复一次即可（按记录时间取新，不会互相覆盖掉新增内容）。

> 注意：部分公共 Wi-Fi / 校园网会隔离设备互访，这种情况无法互连，属正常现象。

### 4. 备份

`我的 → 备份与恢复`：默认自动备份（最近 15 份）；也可导出 JSON 到手机「下载」目录，传到电脑或网盘长期保存；换机后「从文件导入」即可恢复。

## 🔒 隐私与安全

- **没有账号、没有云端、没有广告**，所有数据保存在手机本地 WebView 存储中；
- **没有申请网络权限**（`INTERNET` 仅用于同一 Wi-Fi 下的设备互连，App 内置的局域网同步服务带 4 位连接码，关闭后立即停止，不会访问任何外网）；
- 备份文件只写到你手机的「下载」目录，不会上传；
- 卸载会清空数据，换机前请先导出备份。

## 🛠 技术实现

- **外壳**：原生 Android `WebView`（单 Activity，~500 行 Java），提供 JS 桥：震动、屏幕常亮、TTS 朗读、系统文件选择器、文件导出、局域网同步服务；
- **界面**：纯 HTML/CSS/JS（无框架、无构建工具、无网络依赖），深色/浅色 + 5 套主题色全部走 CSS 变量；
- **数据**：`localStorage`（键 `yuyue.study.v1`），备份键 `yuyue.bk.*`；
- **构建**：不用 Android Studio / Gradle，`build.ps1` 调 `aapt2 → javac → d8 → zipalign → apksigner` 直接产出签名 APK（只需本机 JDK 21 + Android SDK build-tools）；
- **质量保障**：`tools/qa.ps1` 跑 31 项自动交互测试（含新用户欢迎流程、导入课表、备份、主题色、番茄自定义等），`tools/shots.ps1` 在 6 种视口 × 深浅主题下自动截图，`apksigner verify` + 包内 assets 哈希一致性校验。

### 从源码构建

```powershell
git clone https://github.com/<你的用户名>/<仓库名>.git
cd study-planner
pwsh -File .\build.ps1                 # 产出 dist\YuYueStudy.apk
# 或指定版本
pwsh -File .\build.ps1 -OutName "YuYueStudy-v1.5.2.apk" -VersionCode 7 -VersionName "1.5.2"
```

> 版本号以 `app/AndroidManifest.xml` 的 `versionCode / versionName` 为准（aapt2 的参数会被 manifest 覆盖）。

## ⚠️ 已知限制

- **设备互连需要同一 Wi-Fi 且路由器允许设备互访**；不支持跨网段 / 热点中继；
- 没有云同步 —— 这是刻意设计，换机请用备份导入；
- 单词发音依赖手机系统 TTS 引擎（多数国行手机自带；无声时安装系统语音引擎即可）；
- 词库为四六级范围扩充数据，个别释义/音标可能有误差，欢迎反馈修正；
- 课表按「周几」排课，不区分单双周，不处理节假日调休；
- 界面依赖系统 WebView；较旧 WebView 会自动启用兼容样式（观感会略有简化），建议在「设置 → 关于 → 设备与兼容性」确认版本。

## ❓ FAQ

**Q：为什么安装包只有 500 多 KB？**
A：界面是纯 HTML/CSS/JS，没有引入任何框架和图片素材，图标与插画全部由代码/矢量绘制，词库是纯文本数据。

**Q：真的不联网吗？**
A：除了你主动开启的「设备互连」（局域网点对点），App 不会发起任何网络请求，也没有账号体系。

**Q：换手机怎么迁移？**
A：旧手机「备份与恢复 → 导出到文件」，把 JSON 传到新手机，「从文件导入」。

**Q：为什么两台设备连不上？**
A：先确认同一 Wi-Fi；部分公共网络/校园网隔离设备互访，可改用手机热点让两台设备连接。

**Q：能上架应用商店吗？**
A：当前是本地自签名安装包，走 sideload；如需上架需提交应用商店审核并签对应渠道包。
